INSTALLAZIONE SEMPLICE NEL REPOSITORY GIA' ESISTENTE
1. Prima crea una copia di backup del sito già presente su GitHub.
2. Estrai lo ZIP: contiene subito index.html nella radice (non c'è una cartella da eliminare).
3. Copia i file estratti sulla RADICE del repository DELGROSSO-viaggi, scegliendo
   di AGGIORNARE soltanto i file con lo stesso nome. Aggiungi gli altri file nuovi.
4. NON CANCELLARE I FILE NON PRESENTI NELLO ZIP: la versione futuristica conserva
   la prenotazione preesistente, il backend, l'area riservata e la configurazione.
5. Usa un'anteprima Vercel prima di pubblicare il nuovo sito sul dominio.
