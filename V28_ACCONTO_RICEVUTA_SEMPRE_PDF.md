# V28 — Ricevuta acconto sempre disponibile

- Ogni Acconto/Saldo genera sempre la ricevuta PDF.
- Se il cliente ha email, il PDF viene archiviato e inviato via email quando SMTP è disponibile.
- Se il cliente non ha email, il PDF viene scaricato automaticamente sul dispositivo dell'operatore.
- Le ricevute archiviate hanno un pulsante Scarica PDF nel Gestionale.
- Nessuna configurazione WhatsApp/Twilio richiesta.
